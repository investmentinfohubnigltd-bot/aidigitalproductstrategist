# Aurum Engineering Standard v2 Adoption

This repository is being retrofitted to the Aurum Engineering Standard v2. The first gate adds deterministic install, static type checking, linting, production build and high-severity dependency audit on pull requests and main.

This baseline does not by itself establish full compliance. Product-specific architecture, data governance, security, privacy, incident response, continuity, third-party, testing, smoke-test and operational-evidence controls remain subject to repository-specific audit and remediation.
